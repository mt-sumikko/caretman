# 棒人間のモーション（キャレットの状態と表現）

棒人間が見せるモーションは、以下の状態遷移に基づいて決まります。**発生条件はキャレットの状態・移動・時間経過から判定される** ため、ユーザーの操作や意図とは一度のを置いて記載しています。

| 状態 | 発生条件 | 表現 |
| --- | --- | --- |
| **打っている（歩行）** | 直近300ms以内にキャレット位置が変わった | 横から見た連続的な歩行サイクル（1周期0.56秒）。移動方向に歩く。足は接地中に後ろへ流れ、浮いている間に膝を前へ出して振り出す。脚が開いた瞬間に腰が沈む上下動と、脚と逆向きの腕振り |
| **短い待機（基本ポーズ）** | キャレット移動が止まってから300ms〜3.3秒経過 | 腕を下ろした基本ポーズ。歩行から急に「キャレットのフリ」へ移ると慌ただしいため、いったんここで間を持たせる |
| **短い待機（キャレットのフリ）** | キャレット移動が止まってから3.3秒以上、30秒未満経過 | 腕を上げてキャレットのフリをする。不透明度1と0.4をパキッと行き来して点滅（0.53秒周期、完全には消さない）。上げ直しは約0.2秒、下ろすのは即座 |
| **短い待機（文字の間）** | キャレット直後に文字がある、かつ待機中 | 腕・膝・脚を中心軸に寄せ、頭も潰して「横から見た棒」に近い細いシルエット |
| **長い待機（煽り）** | キャレット位置が30秒以上変わらない | 腕を真横に広げ、片膝ずつ曲げて左右に大きく体重移動する「こんなに暇だぞ〜」の動き。左右の端で粘ってから素早く切り替わる |
| **あきらめて座り込む** | キャレット位置が5分以上変わらない | 長い待機からなめらかにあぐらへ遷移 |
| **選択中** | 選択範囲がある（IME変換中の文節ハイライトは除く） | 両腕をほぼ真上に伸ばし、手先だけ右へ向けるポーズ |
| **行またぎジャンプ** | キャレットが行をまたいで移動 | 助走（しゃがんで肘を曲げて踏ん張る）→ 跳躍（脚を畳んで体ごと浮き、頂点で腕を振り上げる）→ 着地の踏ん張り。位置移動は助走が終わったタイミングで行う |
| **削除（放り投げ）** | キャレット直前の文字が削除された（Backspace/Delete） | 左足を踏み込んで腰を落とし、足元から両手で掬う溜め → 体をのけぞらせて画面右上へ全力で振り抜く → 余韻 → 戻り。削除した文字量が多いほど動きが長くなる |
| **貼り付け** | クリップボードのテキストが挿入された（Ctrl+V など） | 前傾して腰を落とし、両腕を画面左へ突き出して全力で押し込む構え。貼り付けた文字量が多いほど動きが長くなる |
| **複数文字ホップ** | キャレットが同一行内で1.5文字以上横移動 | 移動方向へ突き出した肘に引っぱられるように飛び出す。上半身はほぼ起こしたまま後ろ脚を斜めに蹴り出す。左右で反転 |
| **変換中（IME）** | 入力メソッド変換中（compositionstart 〜 compositionend） | 不透明度を0.4まで落とし、変換候補と被らないようにする。入力中は変換文字末尾に追従して歩き、候補を選んでいる間はその場で待つ |
| **フォーカス外れ** | エディタが blur した | 常時の微振動（line boil）を止め、不透明度を0.5に落とす |
| **フォーカス復帰** | エディタが focus した | 微振動を再開し、不透明度を元に戻す |
