# caretman

テキスト入力中に表示される点滅キャレット(カーソル)を、鉛筆描き風の棒人間アニメーションに置き換えたミニマルなWebテキストエディタ。

## コンセプト

- キャレットを「状態を持つキャラクター」に置き換えることそのものを主役にした、実験的なエディタ
- 打鍵中は歩き、何もしなければ手持ち無沙汰に待ち、長く放置すると煽ってから諦めて座り込む、文字を消すと放り投げる…など、キャレットの動きそのものを棒人間の一連のモーションとして表現する
- 絵柄の方向性は「鉛筆で描いたような揺らぎ・不完全さ・手の温度を感じる質感」(Don't: SVGできれいに描けるような幾何学的な線)
- ログイン・アカウント登録なしで、すぐに遊べるシンプルなWebページであることを優先する

初期の企画意図・検討過程は [`docs/`](./docs) 以下の仕様書・プロトタイプを参照。

## 基本的な仕様

### 棒人間のモーション(キャレットの状態)

| 状態 | 発生条件(目安) | 内容 |
| --- | --- | --- |
| 打っている(歩行) | 直近300ms以内に入力・移動があった | 4コマの歩行サイクルをスナップ切替。速さに関わらず常に「歩き」で統一 |
| 短い待機(基本ポーズ) | 入力/移動が止まってから300ms〜3.3秒 | 腕を下ろした基本ポーズのまま。歩行から急に「キャレットのフリ」へ移ると慌ただしいため、いったんここで間を持たせる |
| 短い待機(キャレットのフリ) | 上記からさらに3秒(=計3.3秒)経過、10秒未満 | 腕を上げてキャレットのフリをするポーズ。上げ直しは約0.2秒かけてゆっくり、下ろすのは即座 |
| 短い待機(文字の間) | 上記の待機中、かつキャレットの後ろに文字がある | 腕・膝・脚を中心軸に寄せ、頭も潰して「横から見た棒」に近い細いシルエットにする |
| 長い待機(煽り) | 10秒以上、何も操作がない | 体重を左右に移しながら大きく揺れる、挑発的なモーション |
| あきらめて着席 | 長い待機からさらに5分経過 | なめらかにしゃがみ込むポーズへ遷移 |
| 選択中 | テキスト選択中(ダブル/トリプルクリックの単語・行選択も含む) | 両腕をほぼ真上に伸ばし、手先だけ右へ向けるポーズ |
| 行またぎジャンプ | Enter、行を跨ぐBackspace/矢印キー/クリックなど | 助走→跳躍→着地の3段階。位置移動は助走が終わったタイミングで、跳躍と同時に行う |
| 削除(放り投げ) | Backspace/Deleteで文字を削除 | 両手で掴んで画面右へ振り抜くジェスチャー。削除した文字量が多いほど余韻を長くする |
| ホップ | Home/End・複数文字移動・IME変換確定・遠距離クリックなど、同一行内の大きな移動 | 小さく跳ねるだけの軽いモーション |
| 変換中 | IME変換中(compositionstart〜compositionend) | 不透明度を0.4まで落とし、変換候補の文字と被らないようにする |
| フォーカス外れ/復帰 | エディタのblur/focus | 常時の微振動(line boil)を止め、不透明度を0.5に落とす/元に戻す |

棒人間のサイズはエディタのフォントサイズに連動し、縦位置は文字のベースラインに揃える。

### MVP機能

- ログイン・アカウント登録なし
- 入力内容をlocalStorageへ自動保存(400msデバウンス)。初回のみ「このブラウザに自動保存されます」という案内を表示(導入デモの再生後まで表示タイミングをずらしている)
- 初回訪問時だけ、自動でタイプ→削除するイントロデモを再生
- PC: ヘッダーから `.txt` / `.md` としてダウンロード
- SP(実機のモバイル端末でnavigator.share対応時): OS標準の共有シートから `.txt` / `.md` をファイル共有。共有シートは実機かどうかをUser-Agentで判定して切り替え、非対応環境ではPCと同じダウンロードにフォールバックする

### 絵柄・描画

- 頭・肩・肘・腰・膝・足などの座標を毎フレーム計算し、線で結ぶ手続き型(procedural)のアニメーション
- rough.js で線の頂点をランダムに揺らして手描き風の形にし、静的なテクスチャ画像をSVGの`<mask>`で重ねて鉛筆の擦れ・粒感を表現
- SVGの`viewBox`は固定したまま表示サイズ(width/height)だけをフォントサイズに連動させることで、rough.jsのパラメータを固定値のままフォントサイズ変化に追従させている

## 技術スタック

- [Vite](https://vitejs.dev/) + TypeScript(UIフレームワークなし、素のDOM操作)
- [rough.js](https://roughjs.com/)
- デプロイ先: ロリポップ！デプロイナウ(`npm run build`で生成される`dist/`を静的配信)

## ディレクトリ構成

```
index.html            本体(エディタ)のHTML
motion-review.html     モーション調整専用の別ツール(本体と独立して反復調整できるようにしたもの)
src/
  main.ts              起動処理・自動保存/共有・ダウンロードUIの配線
  editor.ts             contenteditableのイベント処理、キャレット追従
  pose.ts                棒人間のポーズ計算(状態機械)
  render.ts              rough.js + SVGでの実際の描画
  autosave.ts            localStorage自動保存
  download.ts            .txt/.mdダウンロード
  introDemo.ts            初回イントロデモ
  debugPanel.ts           開発ビルドのみで読み込まれるデバッグUI(本番ビルドからは自動で除外される)
  motionReview/           motion-review.html用の独立したモーション確認ツール一式
public/textures/         鉛筆テクスチャ画像
docs/                    初期の仕様書・プロトタイプ(企画の経緯の記録)
```

## 開発

```
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド(dist/)
npm run preview   # 本番ビルドのプレビュー
```

`npm run dev` の時だけ、エディタ画面にデバッグパネル(モーション状態表示・各種スライダー・5分経過ボタンなど)が表示される。`import.meta.env.DEV`による分岐のため、本番ビルドには含まれない。
